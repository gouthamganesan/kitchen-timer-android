# Design evidence

`initial-concepts.png` is the original HTML comparison of cream mechanical, enamel/chrome and red-disc directions. It is historical, including labels and controls later removed.

`regular-light.png`, `regular-dark.png`, `focus-light.png`, `focus-dark.png`, `duration-picker.png` and `settings.png` are emulator screenshots of native version 0.1.2, captured on 2026-11-17. They contain only the test app and emulator system chrome. They show appearance, not proof of haptic or alarm quality.

The banner uses the real app icon and separately attributed platform marks. Raw screenshots, logs and device details remain in ignored local artifacts; only these reviewed captures are published.
