What Android permits

Android supplies the header, outer card and action row. Our dial and countdown occupy the custom content area. These previews use 48px for the compact content and 112px for the expanded content; device styling and text scaling will vary. Layout rules.

This visual treatment uses a regular ongoing notification. Android’s promoted Live Updates do not accept custom layouts, so a status-bar chip would need a separate standard design. Live Update rules.

“Ongoing” is user-controlled: Android 14 allows individual dismissal while unlocked. Notifications also need permission on Android 13+. Dismissal rules.

Drag clockwise to add time. Each full turn adds an hour and leaves a coloured layer. The next partial turn is darker. Double tap the centre knob for quick presets. Tap the readout to pick hours and minutes, or type them. Arrow keys adjust by a minute; Shift adjusts by five.

About this prototype

This timer is drawn in HTML, CSS and SVG. No flattened timer images. Start, pause, reset and the sound/vibrate switch work while this page is open. Browser vibration requires a supported device. Android background alarms are outside this visual prototype.
